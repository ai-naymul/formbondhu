অফিসে যাওয়ার আগে ফর্মটা মিলিয়ে নিন। Gemma 4 দেখে বলে দেবে কোথায় ভুল, আর কীভাবে ঠিক করবেন।

Check your paper form or application letter before the trip to the office. Gemma 4 finds what will get it returned and tells you how to fix it.

Gemma কীভাবে যাচাই করে How the AI harness works
  1. পড়া Gemma 4 ছবি দেখে বোঝে এটা ফর্ম না দরখাস্ত, আর প্রতিটি লেখা হুবহু তুলে আনে। Read: Gemma 4 decides whether it is a form or a letter and copies every value exactly as written, plus signature and photo boxes.
  2. মেলানো কোড নথিটিকে একটি নিয়মের কার্ডের সাথে মেলায়; অচেনা নথি হলে সোজাসুজি বলে দেয়। Match: code picks the rule card; an unknown document is refused, never guessed.
  3. যাচাই কোড কার্ডের প্রতিটি নিয়ম মেলায়: তারিখ, আইডি, মোবাইল নম্বর, সঠিক অফিস, স্বাক্ষর। Check: code applies every rule on the card: dates, IDs, phone numbers, the right office, signatures.
  4. আবার দেখা Gemma 4 প্রতিটি সমস্যা ছবিতে আবার দেখে নিশ্চিত করে। Double-check: Gemma 4 looks at the image again; anything it cannot confirm goes to "check yourself".
  5. সমাধান Gemma 4 শুধু নিয়মের লেখা ব্যবহার করে বাংলায় সমাধান লেখে। Fix: Gemma 4 explains each fix in Bangla using only the rule's own text.
  6. দরখাস্ত দরখাস্তের বেলায় Gemma 4 আপনার তথ্য দিয়েই সংশোধিত চিঠি লেখে; কোড পরীক্ষা করে কোনো বানানো আইডি ঢুকল কি না। Draft: for letters, Gemma 4 rewrites the letter from your own details; code removes any student ID the model made up.

Gemma দেখে, কোড সিদ্ধান্ত নেয়। Gemma sees, code decides: every problem points to a written rule, the second look can only remove problems, and fees or offices come only from the rule cards.
